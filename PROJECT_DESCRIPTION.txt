This personal portfolio website introduces Ferse Mol, a B.Tech Artificial Intelligence and Data Science student interested in technology, writing, creativity, and communication. It includes Home, About, Skills, Projects, and Contact sections, along with navigation links and profile links. The website is built using semantic HTML5 and a separate CSS3 stylesheet, with CSS Grid/Flexbox, colour variables, hover/focus states, and responsive media queries for smaller screens. The two featured works are the QueueLess academic project and the article “The India We Don’t See.”
