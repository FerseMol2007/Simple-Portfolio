
🌐 Personal Portfolio Website

Welcome to my personal portfolio website! This project showcases my background, skills, projects, interests, and contact information through a clean, responsive, and user-friendly design.

👩‍💻 About Me

Hi, I'm Ferse Mol, a third-year B.Tech student specializing in Artificial Intelligence and Data Science at RVS Technical Campus, Coimbatore.

I'm interested in technology, content writing, research, creative design, and web development. This portfolio is an opportunity to introduce myself, present my projects, and continue learning through practical experience.

🎯 Project Objective

The objective of this project is to build a personal portfolio website using HTML5 and CSS3 only, demonstrating fundamental web development skills and responsive design principles.

✨ Features

- Home: A welcome section introducing me and my interests.
- About Me: My background, education, and interests.
- Skills: An overview of my technical and creative skills.
- Projects: A showcase of my projects and writing.
- Contact: Ways to connect with me.
- Responsive Design: Layout adapted for desktop and mobile screens.
- Interactive Styling: Hover and focus effects for an improved user experience.

🛠️ Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
- Media Queries
- CSS Custom Properties (Variables)

🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder.
3. Make sure "index.html" and "style.css" are in the same directory.
4. Add your profile photo to the "images" folder.
5. Open "index.html" in your web browser.

No additional software installations or dependencies are required.
